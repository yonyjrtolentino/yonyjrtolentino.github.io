功能

直播所需，一应俱全

用手机在 Twitch 和 YouTube 上做 IRL 直播，并加上实时叠加层（Overlay）。像专业人士一样录制带叠加层的视频。

01 / 06

口袋里的工作室

  • 带图层的场景：后置和前置摄像头、手机屏幕和游戏、图片、视频、文字、浏览器和聊天。
  • 带预览的工作室模式和转场：切换、淡入淡出、滑动、移动和 Stinger。
  • 横屏 16:9 和竖屏 9:16 画布同时输出，适用于 TikTok、Instagram 和 YouTube Shorts。
  • 隐私护盾：通话时或离开游戏时遮住直播画面。
02 / 06

实时叠加层

  • 横条、字幕、滚动条、目标、倒计时和你的社交账号，2000 多种字体。
  • 订阅、Bits、Raid、Super Chat、会员、Kicks 和 TikTok 礼物的自动提醒，带音效和特效（彩纸、爱心、烟花……）。
  • 聊天指令，让观众触发特效和音效。
  • Twitch、YouTube、Kick、TikTok 和 Discord 聊天同屏显示，支持语音朗读。
  • 把叠加层导出到 OBS 和 Streamlabs，或导入你自己的。
03 / 06

多平台推流与录制

  • 通过 RTMP、RTMPS 或 SRT 同时推流到多个平台：Twitch、YouTube、Kick、TikTok LIVE、Instagram 直播、Facebook、X 或你自己的服务器。
  • 最高 4K 60 fps 录制，可暂停，并能保存最近几秒的片段。
  • 硬件 H.264 和 HEVC、自适应码率（Bitrate）和自动重连。
  • 发热和电量控制，支持数小时的长时间直播。
0 dB−6−12−24−48
04 / 06

专业音频

  • 混音器：麦克风、游戏和应用的内部声音、音乐和音效。
  • 人声/游戏平衡、闪避（Ducking）、降噪、压缩器和输出限幅器。
  • 现成的配置：游戏与人声、聊天、播客、背景音乐、ASMR 和户外 IRL。
05 / 06

游戏机、采集卡和摄像头

  • USB（UVC）采集卡，包括 Elgato。
  • 无需采集卡，通过 Wi-Fi 接入 PS5 和 PS4、装有 OBS 的电脑，或用另一部手机作为发送端。
  • 通过 RTSP 接入网络摄像头，通过 RTMP 接入运动相机。
  • 通过 USB 连接 Elgato Stream Deck，以及屏幕快捷按钮。
